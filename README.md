# Flutter Animations Showcase

Implicit, explicit, hero, staggered, flutter_animate aur Lottie demos.

## Setup
1. `flutter create flutter_animations_showcase` (agar nahi banaya)
2. Is zip ka `lib/` folder apni project ke `lib/` ko replace kar dein.
3. `flutter pub add flutter_animate lottie rive`
4. `flutter run`
